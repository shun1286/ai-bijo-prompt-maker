# AI美女プロンプトメーカー

選ぶだけで、整合性の取れた日本語プロンプトを組み立てる無料ツールです。
生成されたプロンプトをコピーして ChatGPT（gptimage2）に貼るだけで、フォトリアルなAI美女画像が作れます。

**▶ 使ってみる: https://shun1286.github.io/ai-bijo-prompt-maker/**

## 特徴

- シーンプリセット23種 × 服装・ポーズ・体型・表情・構図の組み合わせ
- プロンプトは「主題 → 撮影の意図 → 人物 → 服装・ポーズ → 背景・光 → 構図 → 質感 → 避けるもの」の構造化形式
- APIキー不要・登録不要・完全無料。ブラウザだけで動きます

## 使い方

1. シーンと人物設定を選ぶ
2. 「プロンプト生成」→「コピーする」
3. ChatGPTに貼り付けて送信

生成画像の利用は各プラットフォームの規約に従ってください。
